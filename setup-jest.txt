============================
 CONFIGURAÇÃO JEST + ES MODULES
============================

1. INSTALAR
-----------
npm install --save-dev jest


2. ADICIONAR NO package.json
-----------------------------
{
  "type": "module",
  "scripts": {
    "test": "node --experimental-vm-modules node_modules/.bin/jest"
  },
  "jest": {
    "testEnvironment": "node"
  }
}


3. RODAR OS TESTES
------------------
npm test


============================
 POR QUE ESSA CONFIGURAÇÃO?
============================

O Jest por padrão usa CommonJS (require/module.exports).
Como o projeto usa "type": "module" (import/export), é
necessário rodar o Jest com a flag --experimental-vm-modules
para que ele entenda os arquivos .js como ES Modules.

Não é necessário Babel nem nenhuma outra dependência.


============================
 ESTRUTURA DOS ARQUIVOS DE TESTE
============================

Criar uma pasta __tests__ na raiz:

AulaTeste/
├── __tests__/
│   └── navesController.test.js
├── controllers/
│   └── navesController.js
└── ...


============================
 COMO O MOCK DO BANCO FUNCIONA
============================

Nos testes, o banco de dados (database/db.js) é substituído
por um objeto falso usando jest.unstable_mockModule(), que é
a versão compatível com ES Modules do jest.mock().

O banco nunca é chamado de verdade durante os testes.
